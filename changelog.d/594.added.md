**Eleven more API error codes in the `codes` catalog** — `DISK_NOT_READY`,
`INVALID_PARENT_REGION`, `INVALID_PREVIEW_DOMAIN`, `INVALID_SANDBOX_CIDR`,
`INVALID_TOOLBOX_PROXY_URL`, `REGION_LIMIT_REACHED`, `REGION_NOT_EMPTY`,
`REGION_NOT_FOUND`, `REGION_SUBNETS_EXHAUSTED`, `ROLE_IN_USE` and
`RUNNER_HAS_SANDBOXES` are now in `codes.API_ERROR_CODES` and
`codes.CODE_STATUS` in both SDKs, so `is_known_error_code` /
`isKnownErrorCode` recognises them. An error carrying one still raises the
class for its HTTP status (`BadRequestError`, `NotFoundError` or
`ConflictError`), as before.
