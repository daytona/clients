**CLI build contexts honour `.dockerignore`** — `image build --context DIR`
no longer uploads what the context's ignore file excludes, and the 64 MiB
limit counts only what is uploaded. `<Dockerfile>.dockerignore` next to the
Dockerfile takes precedence over the root `.dockerignore`. Every path is
matched with Docker's pattern rules (the last matching pattern wins, a
pattern that matches a parent directory applies to its contents, `!`
re-includes), and an excluded directory is still walked when a `!` pattern
could re-include something inside it, as BuildKit does. The Dockerfile and
the ignore file are always uploaded, even when a pattern matches them. A tar
context is sent as is; `sandbox cp` is unchanged.
