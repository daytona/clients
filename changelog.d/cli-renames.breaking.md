**CLI renames** — `invite show` → `invite get`; `member remove --preview` →
`--dry-run`; `volume create --size-gb` → `--size-gib`; the bucket `volume
create --region` → `--bucket-region`; `sandbox create --cores-max` / `--mem-max`
→ `--cpu-max` / `--memory-max`; `sandbox preview-url` (and `expire`) →
`sandbox port preview-url`. The `image import` alias is removed (use `image
create`).
