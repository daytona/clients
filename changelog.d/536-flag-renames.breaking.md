**CLI: flag renames** — `member remove --preview` → `--dry-run`; `volume create
--size-gb` → `--size-gib`; the bucket `volume create --region` →
`--bucket-region`; `sandbox create --cores-max` / `--mem-max` → `--cpu-max` /
`--memory-max`. An old spelling is a usage error whose hint names the new one.
