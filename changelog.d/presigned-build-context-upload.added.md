**Build from a local context up to 1 GiB:** `images.build_from_context()` / `images.buildFromContext()` upload a tar archive (bytes or a path) straight to storage through `POST /build-contexts` and build from the verified upload, reusing an identical earlier upload instead of sending it again. `daytona image build --context` uploads contexts over 64 MiB the same way, so a directory or tar up to 1 GiB now builds.
