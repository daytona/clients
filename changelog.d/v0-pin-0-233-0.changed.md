**`v0` namespace updated to SDK 0.233.0** — `d.v0` (Python and TypeScript)
now bundles the latest 0.x release, v0.233.0, instead of v0.232.0, and the
migration tools accept projects on 0.233.x without `--allow-newer-v0`. It
brings the 0.x multi-node GPU sandboxes (`SandboxNode`, `NodeResources`,
`CreateSandboxResources` and the node collections) to `.v0`.
