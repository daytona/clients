**Checked bulk write results** — `write_many()` / `writeMany()` parse the response into SDK models: each file needs its `path` and a non-negative `bytes`, and `errors` is required. A response missing one raises `BadRequestError` (400, `BAD_REQUEST`, source `SDK`) instead of an empty string, `0` or an empty list (Python) or the unchecked wire object (TypeScript); Python `BulkWriteResult.errors` no longer has a default.
