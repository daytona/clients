**`v0` namespace updated to SDK 0.231.1** — `d.v0` (Python and TypeScript)
now bundles the latest 0.x release, v0.231.1, instead of v0.230.0, and the
migration tool accepts projects on it without `--allow-newer-v0`. That release
writes `Image.cmd()` / `entrypoint()` exec forms as valid JSON (quotes and
backslashes in an argument no longer break the Dockerfile line), escapes quotes
in `run_commands` / `runCommands` list arguments once instead of twice, and
knows the `L40S` GPU type.
