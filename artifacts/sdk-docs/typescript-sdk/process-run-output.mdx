## collectOutputFromLogs()

```ts
function collectOutputFromLogs(handle: ProcessHandle): Promise<CollectedRunOutput>;
```

Collects a finished (or timed-out) process's retained output by paging the
ledger. Used by run() when no streaming callbacks were requested.

**Parameters**:

- `handle` _ProcessHandle_


**Returns**:

- `Promise<CollectedRunOutput>`

***


## streamOutputWithCallbacks()

```ts
function streamOutputWithCallbacks(
   handle: ProcessHandle, 
   onStdout: (data: string) => void | Promise<void>, 
   onStderr: (data: string) => void | Promise<void>, 
deadlineMs?: number): Promise<CollectedRunOutput>;
```

Streams a process's output live, invoking onStdout/onStderr per frame while
accumulating, until eof or the deadline elapses. Deadline expiry closes the
stream and reports timedOut so run() can surface the same timed_out result a
plain wait() would.

**Parameters**:

- `handle` _ProcessHandle_
- `onStdout` _\(data: string\) =\> void \| Promise\<void\>_
- `onStderr` _\(data: string\) =\> void \| Promise\<void\>_
- `deadlineMs?` _number_


**Returns**:

- `Promise<CollectedRunOutput>`

***
