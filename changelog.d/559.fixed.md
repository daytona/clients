**CLI: `volume create` type** — `--type` and `--size-gib` no longer show a
`disk` / `100` default the CLI never sent: without `--type` the server
chooses the volume's type, and without `--size-gib` its size. A `--type`
other than `disk` or `bucket` (an empty one included) is refused before any
request, as the SDKs refuse it.
