## SandboxNode

Lightweight data-plane handle for one node in a multi-node Sandbox.

**Properties**:

- `cpu` _number_
- `disk` _number_
- `fabricAddress?` _string_
- `fabricHealthy?` _boolean_
- `fabricPrefixLength?` _number_
- `fabricUnhealthySince?` _string_
- `failure?` _GangNodeFailure_
- `fs` _FileSystem_
- `gpu` _number_
- `id` _string_
- `incarnation` _number_
- `memory` _number_
- `process` _Process_
- `rank` _number_
- `state` _SandboxState_
- `warnings` _string\[\] = \[\]_ - Advisory RDMA and session-cleanup warnings for this node.



### Constructors

#### Constructor

```ts
new SandboxNode(
   node: import("@daytona/api-client").SandboxNode,
   toolboxProxyUrl: string, 
   clientConfig: Configuration, 
   sandboxApi: SandboxApi, 
   language?: string, 
   requestTimeoutMs?: number
): SandboxNode;
```

**Parameters**:

- `node` _API SandboxNode DTO_ - Node data from the API response (rank, id, state and resources), not an SDK node handle.
- `toolboxProxyUrl` _string_
- `clientConfig` _Configuration_
- `sandboxApi` _SandboxApi_
- `language?` _string_
- `requestTimeoutMs?` _number_


**Returns**:

- `SandboxNode`
