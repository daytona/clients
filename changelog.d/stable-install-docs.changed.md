**Install instructions** — the Python, TypeScript, CLI and migration-tool
READMEs now install the latest stable 2.x release by default (`pip install
daytona`, `npm install @daytona/sdk`, `brew install daytonaio/cli/daytona`,
`uvx daytona-upgrade`, `npx @daytona/upgrade`); alpha and release-candidate
channels are documented as explicit opt-ins.
