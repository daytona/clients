**LSP error codes removed** — the toolbox no longer has an LSP surface, so
the `LSP_SERVER_UNAVAILABLE` and `LSP_NOT_STARTED` error codes and their
`LspServerUnavailableError` / `LspNotStartedError` classes are removed from
both v2 SDKs, and `toolbox:lsp` is no longer listed as a sandbox access-token
operation.
