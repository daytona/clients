**Clearer method names** — process handles: `stdin()` / `stdinEof()` (`stdin()` / `stdin_eof()`) become `writeStdin()` / `closeStdin()` (`write_stdin()` / `close_stdin()`), and the `eof` option is gone (call `closeStdin()`). Files: TypeScript `read()` / `write()` / `rm()` become `readBytes()` / `writeBytes()` / `remove()` (`writeBytes()` takes bytes only; use `writeText()` for strings), Python `fs.delete()` becomes `fs.remove()`, and in both SDKs `find()` (file contents) becomes `grep()` and `search()` (file names) becomes `glob()`. Computer use: the screenshot methods (`capture`, `region`, `captureCompressed`, `regionCompressed` and their `screenshot*` aliases) merge into one `screen.screenshot({ region, format, quality, scale, showCursor })`; `region` is a `ComputerUseRegion`. LSP: `didOpen()` / `didClose()` (`did_open()` / `did_close()`) become `openDocument()` / `closeDocument()` (`open_document()` / `close_document()`). Python: `ProcessHandle.attach()`, which always raised, is removed.
