**`v0` namespace updated to SDK 0.232.0** — `d.v0` (Python and TypeScript)
now bundles the latest 0.x release, v0.232.0, instead of v0.231.1, and the
migration tools accept projects on 0.232.x without `--allow-newer-v0`. It
brings two 0.x fixes: Python build-log streams no longer time out after five
minutes, and `Image.pip_install` / `pipInstall` package names are no longer
parsed as pip options.
