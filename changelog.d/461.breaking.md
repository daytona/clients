**Clearer method names** — breaking renames in both SDKs:
process handles `stdin()` / `stdinEof()` (Python `stdin()` / `stdin_eof()`)
become `writeStdin()` / `closeStdin()` (`write_stdin()` / `close_stdin()`),
and the `eof` option is gone (call `closeStdin()` instead). Files:
TypeScript `read()` / `write()` / `rm()` become `readBytes()` /
`writeBytes()` / `remove()` (`writeBytes()` takes bytes only; use
`writeText()` for strings), Python `fs.delete()` becomes `fs.remove()`, and
in both SDKs `find()` (file contents) becomes `grep()` and `search()` (file
names) becomes `glob()`. Computer use: TypeScript `capture()`, `region()`,
`captureCompressed()`, `regionCompressed()` and their `screenshot*` aliases,
and Python `capture()`, `region()`, `capture_compressed()` and
`region_compressed()`, merge into one `screen.screenshot()` taking `region`,
`format`, `quality`, `scale` and `showCursor` (`show_cursor`); `region` is a
`ComputerUseRegion`, and the image is compressed when any of `format`,
`quality` or `scale` is set. The TypeScript types
`ComputerUseScreenshotRegionOptions`, `ComputerUseScreenshotCompressedOptions`
and `ComputerUseScreenshotRegionCompressedOptions` are replaced by
`ComputerUseScreenshotOptions`. LSP: `didOpen()` / `didClose()` (`did_open()` /
`did_close()`) become `openDocument()` / `closeDocument()`
(`open_document()` / `close_document()`). Python: `ProcessHandle.attach()`,
which always raised, is removed.
