**CLI build contexts honour `.dockerignore`** — `image build --context DIR`
no longer uploads what the context's ignore file excludes, and the 64 MiB
limit counts only what is uploaded. Matching follows Docker's pattern matcher
(the classic builder's): `<Dockerfile>.dockerignore` next to the Dockerfile
takes precedence over the root `.dockerignore`, the last matching pattern
wins, a pattern that matches a parent directory applies to its contents, and
`!` exceptions re-include. A tar context is sent as is; `sandbox cp` is
unchanged.
