**Migration tool: the `--json` report can grow within 2.x** — from `2.0.0` on,
the flags, exit codes and existing `--json` report fields and values of
`npx @daytona/upgrade` / `uvx daytona-upgrade` stay compatible within a major
version, while a minor release can add flags, report fields and new
`language`, `mode`, `kind`, `refused.reason` and `suggestion.category` values.
`upgrade/mapping/report.schema.json` now accepts fields and values it doesn't
list, so a report from a later 2.x release still validates; ignore the ones
you don't know.
