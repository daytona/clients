# Changelog

All notable changes to the Daytona SDKs (Python [`daytona`](https://pypi.org/project/daytona/)
and TypeScript [`@daytona/sdk`](https://www.npmjs.com/package/@daytona/sdk)) are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the SDKs follow [Semantic Versioning](https://semver.org/) — see
[VERSIONING.md](docs/VERSIONING.md). Both SDKs share a version line and are released
together.

There is no `Unreleased` section in this file. Unreleased changes live as one
fragment per user-visible change under [`changelog.d/`](changelog.d/) and are folded in here when
a version is cut (see [RELEASING.md](docs/RELEASING.md) and
[`changelog.d/README.md`](changelog.d/README.md)).
