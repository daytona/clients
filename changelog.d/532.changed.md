**Migration tool: the `--json` report can grow within 2.x** — the flags, exit
codes and existing `--json` report fields of `npx @daytona/upgrade` /
`uvx daytona-upgrade` stay compatible within a major version, while a minor
release can add report fields and new `kind` / `refused.reason` values.
`upgrade/mapping/report.schema.json` now accepts fields and values it doesn't
list, so a report from a later 2.x release still validates; ignore the ones
you don't know.
